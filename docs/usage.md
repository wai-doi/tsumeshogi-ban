# 使い方

## 基本

- 駒はドラッグ＆ドロップで移動します。
- ページを開くと編集モードで開始します。
- 以前に `解答を開始` で保存した配置がある場合、起動時にその配置が読み込まれます。

## 編集モード（盤面を作る）

1. 駒箱・盤上・駒台の間で駒をドラッグして配置します。
2. 盤上の駒を右クリックまたはダブルクリックすると、駒の状態を切り替えられます。
3. 局面ができたら `解答を開始` を押します。
4. 必要に応じて `保存データを削除` / `盤面を初期化` を使います。

右クリック / ダブルクリックでの切り替えルール:

- 成れる駒（歩・香・桂・銀・角・飛）: 先手 → 先手成 → 後手 → 後手成 → 先手...
- 成れない駒（金・玉）: 先手 ↔ 後手

補足:

- `解答を開始` で、現在の配置をブラウザに保存して解答モードへ切り替えます。
- `保存データを削除` は、ブラウザに保存済みの配置だけを削除します。
- `盤面を初期化` は、現在の編集中の盤面を初期状態に戻します。

## SFEN入力（編集モード）

- 編集モードの `SFEN` 入力欄に局面を入力して `読込` を押すと、盤面に反映されます。
- `Enter` キーでも読み込みできます。
- 不正な SFEN の場合はエラーが表示され、盤面は変更されません。
- `共有URLをコピー` を押すと、現在の盤面を表す `?sfen=` 付きURLをコピーできます。
- `?sfen=` 付きURLで開くと、起動時にその局面が読み込まれます。

形式:

- `盤面 手番 持ち駒 [手数]`
- 例: `7ks/5+P3/9/9/9/9/9/9/9 b GS`
- 手数（4項目目）は省略できます。

盤面（1項目目）の書き方:

- 9段を `/` で区切って書きます（各段の合計は9マス）。
- 空きマスは `1` 〜 `9` の数字で表します。
- 駒記号は `P L N S G B R K`（歩/香/桂/銀/金/角/飛/玉）を使います。
- 小文字（例: `p`）は後手駒、大文字（例: `P`）は先手駒です。
- 成り駒は `+` を駒記号の前に付けます（例: `+P`）。金・玉には成りを指定できません。

持ち駒（3項目目）の書き方:

- 持ち駒なしは `-`。
- 持ち駒ありは `駒記号` または `枚数+駒記号` を連結します（例: `2GS2p`）。
- 先手持ち駒（大文字）は駒台、後手持ち駒（小文字）は駒箱に配置されます。

注意:

- 手番（2項目目）は `b` または `w` を指定します。
- 現在の実装では、手番（2項目目）と手数（4項目目）は形式チェックのみで、解答開始時の手番や手数表示には反映されません。

## 解答モード（手を進める）

- `解答を開始` で保存した盤面から開始します。
- 手番に応じて動かせる駒が変わります（先手番は先手側、後手番は後手側）。
- 矢印ボタンで手順を前後できます。
- `<<` は初期局面、`<` は1手戻る、`>` は1手進む、`>>` は最新手に移動です。
- `編集に戻る` を押すと編集モードに戻り、盤面は「最後に保存した配置」に戻ります。
