# 使い方

- 駒はドラッグ＆ドロップで、移動させることができます。
- ページを開いた状態では編集モードになっています。

## 編集モード

- 盤上に配置した駒の上で右クリックかダブルクリックをすると、駒を成ることと回転させることができます。
- 詰将棋の駒の配置ができたら、「配置を保存する」ボタンを押してください。
- 「配置を保存する」ボタンを押すと、解答モードに切り替わります。切り替わると同時に、配置がブラウザに保存されます。
- 「保存した配置を消す」ボタン押すと、ブラウザに保存した配置を消すことができます。
- 「配置をクリア」ボタン押すと、配置した駒をすべて片付けることができます。

## 解答モード

- 駒を動かすと手数が進みます。
- 矢印のボタンを押すと、手を進めたり戻したりすることができます。例えば、最初の盤面に戻したい場合は「<<」を押します。
- 「盤面を編集する」ボタンを押すと、編集モードに切り替わります。
