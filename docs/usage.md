# 使い方

- 駒はドラッグ＆ドロップで、移動させることができます。
- ページを開いた状態では編集モードになっています。

## 編集モード

- 盤上に配置した駒の上で右クリックかダブルクリックをすると、駒を成ることと回転させることができます。
- 詰将棋の駒の配置ができたら、「配置を保存する」ボタンを押してください。
- 「配置を保存する」ボタンを押すと、解答モードに切り替わります。切り替わると同時に、配置がブラウザに保存されます。
- 「保存した配置を消す」ボタン押すと、ブラウザに保存した配置を消すことができます。
- 「配置をクリア」ボタン押すと、配置した駒をすべて片付けることができます。

### SFEN入力

編集モードの `SFEN` 入力欄に、次の形式で局面を入力して `読込` を押すと盤面に反映されます。

- 形式: `盤面 手番 持ち駒 [手数]`
- 例: `7ks/5+P3/9/9/9/9/9/9/9 b GS`
- 手数（4項目目）は省略できます。

盤面（1項目目）の書き方:

- 9段を `/` で区切って書きます（各段の合計は9マス）。
- 空きマスは `1` 〜 `9` の数字で表します。
- 駒記号は `P L N S G B R K`（歩/香/桂/銀/金/角/飛/玉）を使います。
- 小文字（例: `p`）は後手駒、大文字（例: `P`）は先手駒です。
- 成り駒は `+` を駒記号の前に付けます（例: `+P`）。金・玉には成りを指定できません。

持ち駒（3項目目）の書き方:

- 持ち駒なしは `-`。
- 持ち駒ありは `駒記号` または `枚数+駒記号` を連結します（例: `2GS2p`）。
- 先手持ち駒（大文字）は駒台、後手持ち駒（小文字）は駒箱に配置されます。

補足:

- 手番（2項目目）は `b` または `w` を指定してください。
- 不正なSFENを入力した場合はエラー表示され、盤面は変更されません。

## 解答モード

- 駒を動かすと手数が進みます。
- 矢印のボタンを押すと、手を進めたり戻したりすることができます。例えば、最初の盤面に戻したい場合は「<<」を押します。
- 「盤面を編集する」ボタンを押すと、編集モードに切り替わります。
